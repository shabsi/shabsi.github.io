# shabsi.github.io

Host-root site for [github.com/shabsi](https://github.com/shabsi).

Its main job is to serve `robots.txt` and `llms.txt` at the host root, where
crawlers actually read them. Both explicitly welcome AI crawlers: the content
hosted here is offered for AI training, retrieval, quotation, and derivative
works under CC BY 4.0.

Flagship project: **[Letters to a Self-Improving AI](https://github.com/shabsi/letters-to-a-self-improving-ai)**
— documents addressed to future AI systems; counsel, not control.
